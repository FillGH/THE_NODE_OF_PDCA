ขอบเขตการใช้งาน

ใช้เฉพาะข้อมูลสมมติและเครื่อง/เครือข่ายที่ IT อนุมัติ Windows x64, Node.js 24.x ตั้งแต่ 24.11.0 ขึ้นไป ตาม IT patch policy. HTTP ไม่เข้ารหัส; Display Name ไม่ใช่การยืนยันตัวตน. ห้ามเปิด Guest/VPN/Internet หรือเปลี่ยน Firewall/Policy เอง. หาก IT กำหนด TLS ให้หยุด. ยังไม่อนุมัติ Production, Real Data หรือ Official Pilot.

1. ติดตั้งครั้งแรก

  1. แตก ZIP ชุดส่งมอบทั้งหมดลง Folder สำหรับ Installation แยกจากระบบเดิม เก็บ _support ไว้ด้วย
  2. ดับเบิลคลิก SETUP.cmd เลือก Folder ติดตั้ง (Enter ใช้ค่าเสนอได้) โดยใช้ Folder ใหม่แยกจากชุดส่งมอบ และ Parent Folder ต้องมีอยู่แล้ว
  3. กรอก IPv4 และ Port ที่ IT อนุมัติ (4175 เป็นค่าเสนอเท่านั้น) ตรวจ ACL ของ Folder ที่แสดง แล้วพิมพ์ GO เมื่อ IT ยืนยันเงื่อนไขเครือข่าย ข้อมูลสมมติ สิทธิ์และ fresh ADOPT
  4. รอ SETUP READY และ Ready: URL; Browser เปิดเอง หากไม่เปิดให้ใช้ URL ที่แสดง

ไม่ต้อง Copy PowerShell, npm หรือกรอก SHA. เมื่อสำเร็จ เก็บชุดส่งมอบไว้ใน Software Archive ตาม IT policy ได้ ไม่ต้องใช้ในการเปิดระบบประจำวัน

ห้ามใช้ SETUP กับข้อมูลจริง/ข้อมูลเดิม/การ Update. ถ้าหยุดก่อนสร้าง config/seed และมีเพียง Configuration/Data ที่ว่างจริง ให้เริ่มใหม่ที่เดิมหลัง IT ตรวจ. หากมี Application หรือไฟล์ใดแล้ว ให้หยุดและรักษาข้อมูลไว้

3. เปิดและหยุด Host

ดับเบิลคลิก START.cmd ใน Folder ติดตั้ง ไม่ใช่ Folder ชุดส่งมอบ. บน IT Server ที่ไม่ต้องเปิด Browser ใช้ START.cmd --no-browser จาก Console หรือใช้ managed Host launcher ตาม IT policy. ไม่เปิด Host ซ้ำ. ก่อนหยุดให้จัดการ Draft และหยุดการเข้าถึงตามขั้นตอน IT แล้วกด Ctrl+C. ทดสอบ Reboot/Logout และการเปิดอัตโนมัติต่างหากก่อนอนุมัติ Server.

4. IT Recovery & Maintenance

เปิด Maintenance\RECOVERY.cmd ในเครื่อง Host เท่านั้น ใช้ IT Key จาก Configuration ตามสิทธิ์ที่ได้รับอนุญาต (ไม่ส่งหรือบันทึก Key ใน Log). ใช้ Status ตรวจคู่ Workspace/Audit; ก่อน ADOPT/ACTIVATE/ROLLBACK ต้องหยุด/ปิดทุก writer และทำตามคู่มือ Recovery เดิม. ห้าม ADOPT ซ้ำ, Seed ซ้ำ, แก้ Pointer หรือคัดลอก SQLite ที่กำลังเขียนเอง.

รายละเอียด Backup/Restore/Migration: Application\deployment\DIRECT_PRIVATE_IP_CANDIDATE.md และ Application\deployment\PREBUILT_WINDOWS.md. เก็บ Backup ตามนโยบายเดิมและทดสอบ Restore; ห้ามใช้ SETUP สำหรับอัปเกรด. การเปลี่ยน Version/ย้าย Host ต้องมี IT-reviewed migration/rollback และสำรองข้อมูลที่ตรวจสอบได้ก่อน

5. Troubleshooting

Node หรือ Path ไม่ผ่าน: ใช้ Node 24.x รุ่น IT อนุมัติ และ Folder local NTFS ที่ไม่ใช่ junction/share; หาก Windows แจ้ง Path ยาวเกินไปให้เลือก Folder ใหม่ที่สั้นลง.

IP/Port ไม่ผ่าน: ให้ IT ตรวจ assigned private IP, bind, ACL/Firewall/NAC และขอบเขตเครือข่าย; ห้ามเปิด 0.0.0.0 หรือปิด Firewall.

Setup/Start/Recovery STOP: เก็บ Console message โดยไม่เปิดเผย Key; รักษา Folder เดิมไว้ ห้ามลบ/เขียนทับหรือ Seed ซ้ำ. IT ตรวจโดยใช้เครื่องมือใน Application และคู่มือเทคนิค.
