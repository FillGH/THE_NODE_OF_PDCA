# ข้อความให้ Phil ใช้ประสาน IT

**สถานะ 8 พฤศจิกายน 2026** · Phil รับรองแบบ DESIGN · ส่งต่อทีม IT สำหรับเตรียมการตั้งค่าและ VERIFY

## ข้อความพร้อมส่ง

สวัสดีทีม IT ครับ

ขอให้ช่วยยืนยันแบบการใช้งาน THE NODE OF PDCA สำหรับ Pilot ภายในโรงงานครับ แผนคือใช้ laptop เป็น Host ชั่วคราว ให้เฉพาะกลุ่มผู้ใช้ Float Monitor ที่ได้รับอนุญาตเข้าผ่าน LAN โรงงานบนเครื่อง Desktop สำรองข้อมูลทั้งชุดบน Host ทุก 2 ชั่วโมงขณะเปิดเครื่องและเก็บย้อนหลัง 30 วัน เป้าหมายเมื่อมีชุดสำรองที่กู้ได้คือเสียข้อมูลที่บันทึกแล้วไม่เกิน 4 ชั่วโมงและกลับมาใช้งานได้ภายใน 1 วันทำการ รอบนี้ขอคำตอบเพื่อปิดแบบก่อนเริ่มพัฒนา

1. **สิทธิ์บน LAN** ใช้วิธีใดจำกัดให้เฉพาะเครื่องและกลุ่มผู้ใช้ที่ได้รับอนุญาต และใครอนุมัติ/เพิ่ม/ถอนสิทธิ์ ช่วยยืนยันวิธีปฏิเสธเครื่อง LAN ที่ไม่มีสิทธิ์และการเข้าตรงจาก Internet หรือ Company VPN ชื่อที่ผู้ใช้กรอกในแอปใช้แสดงผู้แก้และ History เท่านั้น
2. **เครื่องใช้ร่วมกัน** ขอวิธีที่ IT อนุญาตเพื่อแยกผู้ใช้และทำให้คนถัดไปเปิด draft เดิมไม่ได้ รวมทั้งตอนลืมจบ Session เช่น นโยบายโปรไฟล์เครื่อง/เบราว์เซอร์ การล็อกเครื่อง และการหมดอายุ พร้อมระบุ Edge/Chrome รุ่นหรือการตั้งค่าคืนแท็บที่ใช้กับเครื่อง Pilot
3. **Host และการเปิดบริการ** laptop ได้รับอนุญาตให้เป็น Host หรือไม่ มีข้อกำหนดเครื่องและพื้นที่สำหรับข้อมูล รูป และชุดสำรอง 30 วันอย่างไร บริการและงานสำรองจะเริ่มเองหลังเปิดเครื่องโดยไม่ต้องให้คนเปิดแอปได้ด้วยวิธีใด ขอผู้รับแจ้งเมื่อสำรองล้มเหลว เวลาทำการที่ใช้นับ RTO และข้อจำกัดเมื่อต้องย้ายไปเครื่องร่วมกับ Float Monitor
4. **ผู้ดูแล** ขอชื่อผู้ดูแลหลัก ผู้ดูแลสำรอง และผู้ดูแลเทคนิค พร้อมช่องทางติดต่อและผู้รับช่วงเมื่อผู้ดูแลหลักไม่อยู่ ผู้ดูแลเทคนิคอาจเป็นคนเดียวกับหนึ่งในสองบทบาทแรกหาก IT และเจ้าตัวยืนยัน
5. **Audit หลังลบถาวร** ขอระยะเก็บบันทึก Delete/Restore/Purge หลัง purge จุดเริ่มนับ รายการข้อมูลที่เก็บได้รวมถึง Display Name/Session ID ผู้มีสิทธิ์อ่าน และวิธีลบเมื่อครบอายุ ทั้ง Node และ PDCA
6. **กู้จาก Backup เก่า** หากชุดสำรองยังมี Node/PDCA ที่เข้า Trash หรือถูก purge หลังเวลาของชุดสำรอง ให้ปฏิบัติอย่างไรกับ snapshot และข้อมูลที่กู้ในพื้นที่แยก ต้องใช้หลักฐานจากที่ใดเพื่อคืนสถานะ Trash พร้อมวันหมดอายุเดิมหรือคัดรายการที่ purge แล้วออกก่อนเปิดใช้ ใครตรวจอนุมัติ และถ้าหลักฐานการลบไม่ครบให้ดำเนินการอย่างไร

ตอบแยกข้อพร้อมเงื่อนไขหรือชื่อผู้ให้คำยืนยันได้เลยครับ ถ้ามีข้อที่ต้องส่งให้ฝ่ายอื่นช่วยระบุผู้รับผิดชอบด้วย ขอบคุณครับ
