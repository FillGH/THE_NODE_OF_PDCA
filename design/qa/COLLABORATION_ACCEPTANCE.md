## ชุดตั้งต้น

รีเซ็ต [ต้นแบบเดิม](../prototypes/DESIGN_collaboration-recovery.html) ก่อนแต่ละกรณี หรือใช้ข้อมูลเดียวกันบนระบบที่ได้รับอนุมัติให้ทดสอบในภายหลัง A และ B เป็นคนละ Session แต่ใช้ Display Name “ผู้ทดสอบ” เหมือนกัน A เปิดสองแท็บ A1/A2 ใน PDCA เดียวกัน และ B ใช้ B1 เริ่มที่ Fact ฉบับ r1 (“พบรอยรั่วในชุดแรก”) อีก Node คือ Action ฉบับ r1 (“ทดลองอุ่นหัวซีล”) ใช้ข้อความ a1, a2, b1 ที่แยกแยะได้และบันทึกลำดับเหตุการณ์กับ revision ที่ผู้อ่านเห็นทุกครั้ง

## ข้อกำหนดกับแบบที่เสนอ

- **ยืนยันแล้ว** ผู้ชมเห็นเฉพาะฉบับที่บันทึกแล้ว การบันทึกสำเร็จและการตอบกลับถึงแท็บผู้แก้อาจเกิดคนละเวลา ใช้ lock ต่อ Node และแท็บแก้ไขหนึ่งแท็บต่อ Session ต่อ PDCA หยุดแก้เมื่อขาดการเชื่อมต่อและยืนยันก่อนส่ง draft ใหม่ กู้ draft ได้ใน Session เดิมตามขอบเขตที่ Phil ยืนยันและบันทึกใน DESIGN_PRE_BUILD
- **แบบเพื่อให้ BUILD ตรวจรับได้** ผูกคำขอบันทึกกับชุดข้อมูลที่ส่ง, ID คำขอ, revision ฐาน และสิทธิ์การแก้รอบนั้น ตรวจเงื่อนไขตอนเขียนข้อมูลและเก็บ History ในการบันทึกครั้งเดียวกัน หากผลยังไม่ทราบ ให้ตรวจผลก่อนส่งใหม่และแยกจาก draft ที่พิมพ์ต่อ เมื่อไม่มีผลที่เชื่อถือได้ให้เทียบฉบับล่าสุดและขอผู้ใช้ยืนยันการเปลี่ยนอีกครั้งตามกติกาเดิม
- **การใช้เครื่องและ Session** Phil ยืนยันให้ผู้ใช้ Pilot ใช้เครื่องแยกกัน ทดสอบว่ากู้ draft ได้เฉพาะ Session เดิมที่ยังมีชีวิตและการเปิดเบราว์เซอร์ใหม่รวมการคืนแท็บใช้ Session ใหม่ หากจะใช้เครื่องร่วมให้ยืนยันวิธีแยกผู้ใช้ตาม IT-02 ก่อน เกณฑ์ lock หมดอายุและการกู้แท็บต้องทำซ้ำได้ใน BUILD ช่วงที่ 2

## สถานะหลักฐาน

**PASS ในตัวจำลอง** ตรวจซ้ำ 6 กรณีด้วยการเรียกสถานะในต้นแบบเดิม ได้แก่ บันทึกสำเร็จและล้มเหลว (C-01/C-02), บันทึกคนละ Node (C-05), ปฏิเสธฉบับที่เปลี่ยนหลังเปิดหน้าตรวจ (C-06), ขอแท็บแก้ไขและกู้จากอีกแท็บที่จำลองไว้ (C-07), และล้าง draft เมื่อเปลี่ยน Session (C-09) ผลนี้ตรวจเฉพาะการเปลี่ยนข้อมูลในหน้าเดียว ส่วนผลทบทวนหน้าจอและการส่งต่อเครื่องในเดโมอ้างตามรายงานเดิม

**PASS เพิ่มในหน้าเดโมที่ 1920 × 1080** เลือก **Host บันทึกแล้ว แต่ผลมาช้า** เพื่อให้ผู้ชมเห็น r2 ก่อนผู้แก้ได้ผล ตรวจว่าการประมวลผลคำขอเดิมซ้ำไม่เพิ่ม revision ผลเก่าไม่ล้าง a2 และการเชื่อมกลับต้องให้ตรวจ a2 ก่อนส่ง เลือก **คำขอเดิมมาถึงหลังเสียล็อก** เพื่อให้ B บันทึก b1 ก่อนและตรวจว่า Host จำลองปฏิเสธคำขอของ A ลองจบ Session หลัง Host บันทึกแต่ก่อนส่งผลได้ด้วย ฉบับที่บันทึกยังอยู่และผลเก่าไม่เปิด Session เดิม (C-03/C-04/C-09 เฉพาะส่วนที่หน้าเดียวจำลองได้)

**NOT TESTED บนระบบรวม** ผลตอบกลับและประวัติบน Host จริง การปิดเบราว์เซอร์ทั้งหมด การคืนแท็บ การแยกสิทธิ์ และการชนจากหลายเครื่องต้องตรวจตามตารางเมื่อมีระบบและสภาพแวดล้อมที่ได้รับอนุญาต
